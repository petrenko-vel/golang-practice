# Go Backend Roadmap: от новичка до Middle

Цель: подготовка к работе Go Backend Developer. Язык, сети, базы данных, конкурентность, архитектура, тестирование, Linux, Docker, CI/CD.

Принцип: сначала стандартная библиотека и базовые инструменты, потом фреймворки. Нужно понимать, что делает инструмент и зачем он нужен, а не только знать его API.

Нагрузка: 7-10 часов в неделю. Ориентируйся на последовательность, а не на жёсткие даты.

---

## Стек

| Область | Основной выбор |
|---|---|
| Язык | Go, актуальная стабильная версия |
| Инструменты | go, gofmt, go vet, go test, golangci-lint |
| HTTP | net/http, затем по необходимости Chi или Gin |
| БД | PostgreSQL + pgx |
| SQL-запросы | SQL вручную, затем sqlc по необходимости |
| Миграции | golang-migrate или goose |
| Кэш | Redis |
| Тестирование | testing, httptest, Testcontainers |
| API-документация | OpenAPI / Swagger |
| Контейнеры | Docker, Docker Compose |
| CI/CD | GitHub Actions |
| Метрики и трассировка | Prometheus, Grafana, OpenTelemetry |
| Асинхронные задачи | Сначала goroutines и workers, затем очередь сообщений |
| Безопасность | TLS, OAuth 2.0 / OIDC, безопасное хранение секретов |
| Архитектура | Modular Monolith, Clean Architecture там, где она оправдана |

## Порядок обучения

| Период | Основной фокус |
|---|---|
| Недели 1-3 | Инструменты, синтаксис, функции, коллекции |
| Недели 4-6 | Структуры, указатели, интерфейсы, ошибки, пакеты |
| Недели 7-8 | Тестирование и стандартная библиотека |
| Недели 9-10 | Goroutines, каналы, context |

| Недели 14-16 | Архитектура, безопасность, Docker, CI |
| Далее | Redis, очереди, наблюдаемость, продвинутые проекты |

Не переходи к следующему крупному блоку, пока не решила практические задачи по текущему.
